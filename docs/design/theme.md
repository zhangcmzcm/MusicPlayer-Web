# 风与叶 · 嫩叶绿主题

状态：人类已确认 A「嫩叶绿」方向。本文件是 AGENTS.md 第十二节「样式方案」中视觉主题的决策记录与唯一规范来源；`example/index.html` 是配套视觉样例，供浏览器直接查看验收。业务功能不在主题规范范围内。

## 使用方法

后续会话可直接要求：先阅读 `docs/design/theme.md`，再参考 `example/index.html`，沿用已确认的嫩叶绿主题。参考图片不作为项目资源使用。

## 视觉原则

清新、自然、温暖、轻盈。背景像阳光穿过新叶，中央是一整片大白叶，不再叠加矩形卡片。叶片占据视线中心与屏幕大部分高度；叶尖朝右上、叶柄朝左下。表单区域保持纯白，叶脉仅在外围轻轻显露，不穿过文字。

## 配色（以 example/index.html 的 CSS 自定义属性为准）

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--green-light` | `#E6EFCB` | 背景受光区域 |
| `--green-base` | `#C8DDA4` | 嫩叶绿底色 |
| `--green-deep` | `#ABC879` | 背景阴影区域 |
| `--leaf-white` | `#FFFFFF` | 主叶片 |
| `--green-action` | `#62894B` | 主按钮 |
| `--ink` | `#30492F` | 标题与主要文字 |
| `--ink-muted` | `#607153` | 次要文字 |
| `--line` | `#D8E2CE` | 表单边界、细线 |

正式业务中的 hover、disabled、错误色等语义状态需在对应功能切片与人类确认后实现，不从此静态示例推断。

## 造型、排版与装饰

- 原创 SVG 贝塞尔轮廓绘制白叶，柔和绿色投影塑造轻微悬浮感；无照片纹理，不使用参考图作为背景。
- 标题用系统衬线字体，表单和辅助信息用系统无衬线字体，不下载外部字体。
- 桌面表单宽 280px，垂直居中略偏下；输入框为浅色细边框，圆角 12px；主按钮为胶囊形。
- 小叶片分布在四周，避开表单；颜色为淡黄绿，透明度低于主叶片。
- 微风用多条疏朗的白色长曲线表现，避免高密度粒子或明显发光。
- 风线和少量小叶片进行 12–22 秒的缓慢往返动画；主叶片和表单保持稳定。开启 `prefers-reduced-motion` 时停止动画。
- 手机保留白叶视觉，压缩外围留白；矮屏允许纵向滚动，不强行缩小表单文字。

## 范围与复用约束

`example/` 目录只有 `index.html` 登录外观示例（及实施记录 `plan.md`），没有注册页、API、路由、认证、验证、提交或账户逻辑。邮箱和密码只展示空字段，主按钮不可提交，无假数据和虚假成功反馈。

此 HTML 是独立的设计样本，不代表正式工程改用原生 HTML。后续业务实现仍遵循 AGENTS.md 的 Vue 3、JavaScript、Element Plus 约束，并引用此处视觉变量和原创 SVG。

直接在浏览器打开 `example/index.html` 即可查看，不需要 npm、网络或后端。
